## 🎯 Descripción del Portafolio

El portafolio recopila el trabajo realizado semana a semana, sirviendo como registro de conocimientos, avances y prácticas aplicadas. Incluye:

- 📝 **Apuntes de Clase:** Resúmenes teóricos y conceptos clave explicados en cada sesión.
- 💻 **Actividades Prácticas:** Ejercicios, talleres y laboratorios desarrollados en clase o como trabajo independiente.
- 📖 **Recursos y Glosario:** Términos técnicos, documentación de apoyo y enlaces útiles.
- 🚀 **Proyecto del Curso:** Código fuente, documentación y entregables del proyecto final.
